
# AI Traffic Flow Simulation System

## Overview

The AI Traffic Flow Simulation System is a smart traffic management project developed using Python.

This project simulates urban traffic movement using AI-based traffic signal optimization techniques.

The system dynamically adjusts traffic signals based on vehicle density to reduce congestion and improve road efficiency.

---

## Features

- Real-time traffic simulation
- AI-based traffic signal timing
- Dynamic vehicle spawning
- Multi-lane traffic system
- Vehicle counting
- Traffic analytics dashboard
- Machine learning prediction
- CSV traffic data storage
- Smart congestion handling

## AI Functionality

The AI system analyzes traffic density data and dynamically changes traffic signal timings based on congestion levels.

Traffic density levels:
- Low traffic → Short green signal
- Medium traffic → Moderate green signal
- High traffic → Longer green signal
